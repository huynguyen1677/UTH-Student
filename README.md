##  Tính năng nổi bật

|  Tính năng |  Mô tả |
|-----------|-------|
|  **Nạp tiền điểm** | Quản lý số dư điểm, nạp tiền thông qua nhiều phương thức thanh toán |
|  **Lịch sử giao dịch** | Theo dõi chi tiết lịch sử nạp tiền và giao dịch với thống kê real-time |
|  **UTH AI Assistant** | Chatbot AI thông minh trả lời thắc mắc về học tập, quy chế nhà trường |
|  **Thư viện tài liệu** | Khám phá, tìm kiếm và tải xuống tài liệu học tập từ cộng đồng |
|  **Chia sẻ tài liệu** | Đăng tải bài viết, tài liệu riêng để hỗ trợ sinh viên khác |
|  **Cộng đồng sinh viên** | Tạo bài viết, kết nối, thảo luận học tập với bạn cùng trường |

##  Admin Dashboard

Quản lý toàn diện hệ thống ứng dụng, người dùng, giao dịch và nội dung.

🔗 **[Truy cập Admin Panel](https://adminuth.onrender.com/)**

###  Tài khoản Demo
| Thông tin | Chi tiết |
|-----------|---------|
| **Email** | admin1@system.com |
| **Mật khẩu** | admin123 |

### Chức năng Admin
-  **Dashboard** - Thống kê doanh thu, người dùng, hoạt động hệ thống
-  **Quản lý người dùng** - Xem, chỉnh sửa, xóa tài khoản sinh viên
-  **Quản lý hệ thống** - Theo dõi quản lý hoạt động, nhân sự làm việc trong hệ thống, 
-  **Quản lý nhân sự** - Gán role, phân quyền truy cập
-  **Quản lý tài liệu** - Duyệt, kiểm duyệt nội dung từ cộng đồng
-  **Quản lý tài chính** - Theo dõi giao dịch, thanh toán, doanh thu
-  **Quản lý báo cáo** - Quản lý báo cáo các nội dung không lành mạnh trên ứng dụng

##  Cài đặt & Hướng dẫn

###  Yêu cầu hệ thống
- **Android:** 6.0+ (API level 23)
- **iOS:** 12.0+ (nếu hỗ trợ)
- **Kết nối:** Internet ổn định
- **RAM:** Tối thiểu 2GB

###  Hướng dẫn cài đặt

#### 1️ Tải ứng dụng
- [Tải file APK từ GitHub Releases](.)

#### Sử dụng ứng dụng
-  Đăng ký/Đăng nhập bằng tài khoản sinh viên UTH
-  Khám phá các tính năng từ menu chính
-  Hỏi AI Assistant nếu có thắc mắc
